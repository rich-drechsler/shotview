## Legacy Versions

These are legacy versions of the 3D applications that influenced the current version
of shotview. They're included as unsupported reference code that may or may not be
useful.

    shotview-legacy.yx
        The original Yoix implementation that I believe was written in 2012. It
        relied on experimental Java 3D support that was added to Yoix, probably
        sometime in 2004 or 2005.

    shotview-legacy.html
        This is the original browser based implementation that Gemini 3.5 Flash
        and I built in June 2026. The legacy Yoix implementation was the model we
        used to build this version.
